# Подключение сайта к Strapi

На странице `service-and-support.html` добавлен блок «База знаний». Он загружает опубликованные статьи из Strapi через публичный REST API.

## 1. Укажите адрес Strapi

Откройте файл `strapi-knowledge.js` и в начале найдите строку:

```js
const STRAPI_URL = "http://localhost:1337";
```

Если Strapi открыт по другому адресу, замените значение на адрес сервера без `/admin` и без завершающего `/`.

Примеры:

- Админка `http://localhost:1337/admin` → `http://localhost:1337`
- Админка `https://cms.example.ru/admin` → `https://cms.example.ru`

## 2. Разрешите публичное чтение

В панели Strapi откройте:

`Settings` → `Users & Permissions plugin` → `Roles` → `Public`.

В разделе `Article` включите только:

- `find`
- `findOne`

В разделе `Category` включите только:

- `find`
- `findOne`

Нажмите `Save`.

Не включайте для Public действия `create`, `update` и `delete`. Публичному посетителю сайта достаточно читать опубликованные материалы.

## 3. Проверьте публикацию статей

В Content Manager убедитесь, что тестовые статьи имеют статус `Published`. Черновики публичный API не отдаёт.

Поля, которые использует блок:

- `title` — заголовок;
- `content` — текст;
- `published_on` — дата публикации;
- `type` — тип материала;
- `category` — связанная категория;
- `cover` — необязательная обложка.

## 4. Запустите сайт через локальный веб-сервер

Не открывайте страницу двойным щелчком как `file://`. Запустите папку сайта через VS Code Live Server или другой локальный HTTP-сервер, затем откройте `service-and-support.html`.

Если браузер сообщает об ошибке CORS, нужно разрешить origin локального сайта в настройках CORS Strapi. Если сайт размещён на GitHub Pages, Strapi должен быть доступен по публичному HTTPS-адресу, а домен GitHub Pages должен быть разрешён в CORS.

## 5. Что делает блок

Скрипт обращается к адресу:

`/api/articles?populate=*&sort=published_on:desc`

Он показывает опубликованные статьи, категорию, дату, тип, обложку (если она добавлена) и полный текст по нажатию «Читать полностью».

Если API возвращает `403`, проверьте права `find` и `findOne` для ролей `Article` и `Category`. Если появляется ошибка соединения, проверьте `STRAPI_URL`, доступность сервера и CORS.

В браузерный JavaScript не нужно добавлять Admin Token или API Token с правами записи.
